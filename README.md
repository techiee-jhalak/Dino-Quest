## 🎮 How to Play

| Control | Action |
|:---|:---|
| `Space` or `↑` | Jump |
| `↓` | Drop faster while airborne |
| `P` or `Escape` | Pause or resume |
| Tap the game | Jump on mobile |

### 💡 Pro Tips

- Watch ahead and time your jumps before an obstacle gets close.
- Save your shield for a tricky section.
- Answer quizzes correctly to earn points and unlock the next stage.
- Learn from every run and try to beat your best score.

## 🧭 Explore the Project

Dino Quest is a browser game built with HTML5 Canvas, CSS, and vanilla JavaScript. Its Streamlit entry point embeds the existing game so the same runner can be served as a Streamlit app.

<details>
<summary>🗂️ <strong>Project files</strong></summary>

- `index.html` — game layout, HUD, menus, and controls
- `style.css` — responsive dark interface and canvas overlays
- `script.js` — runner gameplay, progression, power-ups, and sound
- `questions.js` — editable multiple-choice question bank
- `streamlit_app.py` — Streamlit wrapper for the browser game
- `requirements.txt` — Python dependencies
- `Dockerfile` — container setup for Railway
- `assets/` — reserved for optional local art and sound assets

</details>

### 💻 Run It Locally

Clone the [GitHub repository](https://github.com/techiee-jhalak/Dino-Quest), then from its folder:

```bash
python -m venv .venv
```

Activate the virtual environment:

```powershell
# Windows PowerShell
.\.venv\Scripts\Activate.ps1
```

```bash
# macOS / Linux
source .venv/bin/activate
```

Install the dependencies and start the Streamlit app:

```bash
pip install -r requirements.txt
streamlit run streamlit_app.py
```

Streamlit prints the local app URL in the terminal.
